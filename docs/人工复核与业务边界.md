# 三档风险策略与人工复核指南（研究原型）

低风险、人工复核、高风险由冻结阈值判定。研究用“自动通过/拒绝”表示路由仿真，不代表已经获批的生产规则；实际授信仍须人工、政策及合规流程。

## 中风险核查清单

核实收入的金额、币种和周期，与年金/申请金额字段是否可比；核实就业特殊值含义，不把365243当真实工作天数或直接认定失业；审查匿名外部分数的来源、获取权限、有效期和覆盖；对异常金额及缺失补充证据；核对申请合同类型和额度需求。真实上线需加入征信、历史履约、现有债务和其他贷前可得信息，并排除观察窗口以后的信息。

人工审查应留存核查项目、材料来源、解释、审核时间、审批理由和申诉渠道。不能把模型高分视为欺诈/违约事实。示例额度系数为低风险1.0、人工通过0.7、高风险0，仅用于情景计算，没有证据证明最优。

## 证券业务迁移限制

原大纲的保证金比例、维持担保比例、持仓集中度、资产波动率与证券交易限制，在已提供的消费信贷主表中没有对应观测。报告只给出“风险档位-额度-业务限制”的框架，不填写似乎真实的监管保证金比例，也不虚构证券持仓。

未来多表应先在各表自然粒度聚合，再按客户/申请ID左关联，验证一行一申请及行数守恒。bureau_balance先按SK_ID_BUREAU聚合并与bureau映射，再按SK_ID_CURR聚合；previous/POS/credit_card/installments必须避免一对多直接拼接造成样本膨胀。历史特征必须满足申请时点可得性。

## 公平和模型风险

本模型排除直接性别、年龄、婚姻和子女数量，但就业、收入来源、证件年数等可能具有代理作用。群体差异表是初步诊断，不是歧视认定或公平认证。小样本群体不计算可解释性不足的AUC或比率基准。

不得把敏感群体特征直接用于差异化阈值。先审查数据、业务合理性、错误影响和申诉，依据批准的治理标准再决定试点方案。
