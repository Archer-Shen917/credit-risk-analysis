# 结项汇报与答辩要点

**一分钟介绍**：本项目用Home Credit公开申请主表研究还款困难风险，而不是汇丰内部或证券实盘数据。在修正第一阶段交叉分析后，完成WOE逻辑回归和LightGBM建模、四轮实验、概率校准、SHAP解释及两套策略模拟。最终随机留出集AUC为0.7336、KS为0.3470。报告明确区分真实测试结果与经济情景假设，不把模拟结果写成银行已实现收益。

## 为什么不直接用两个最高IV的外部分数？
主方案按导师建议保留EXT_SOURCE_2，加入就业时长与贷款收入比，便于说明不同业务维度。两个评分彼此的Pearson相关为正且不高，不能因为它们都与TARGET负相关就判为重复。验证集EXT3增量实验实际上有提升，所以它是受治理取舍影响的候选信息，而非已被证明无效。

## 如何防止数据泄漏？
外层70/30分层；开发集分拟合、调参、校准、策略四组。分箱、填充、盖帽、特征筛选、采样都先在拟合集完成，调参后仅用拟合+调参集重训；校准、阈值各用独立集合，最后一次计算测试指标。由于之前EDA看过全样本，该测试仅是回顾性留出，不冒充完全未知的外部数据。

## 为什么没有直接达到0.78？
0.78是早先材料的示例数字，不是实测目标保证。本次主表、特征治理约束和切分下实测0.7336，必须如实报告。缺失的历史表可能提供新信息，但未收到前不能承诺增益。

## 优化是否显著有效？
相对逻辑回归有明显区分提升。相对LightGBM基线的AUC只提高约0.0010，配对bootstrap区间包含0，不能宣称已证明显著胜出。保留基线作为后续稳健性对照。

## 校准一定更好吗？
不一定。当前单调校准不改变AUC，测试Brier略有上升。保留校准曲线和原概率对照，真实上线前还需新的时间窗验证。

## 策略率能否直接变成银行收益？
不能。TARGET不是经过验证的年度违约概率；LGD、人民币标准额度、利差和人工复核通过率都是假设。策略扩大审批规模时，损失率可能下降但绝对代理损失会上升。只有机构真实业务参数、审批因果实验和时间外表现才能支持实际价值判断。

## 删除性别、年龄就公平了吗？
不是。地区、就业等变量仍可能代理敏感属性，分组批准率差异很大。当前审计提示需复核，不构成公平性或合规认证。

## 为什么没有资产波动率和维持担保比例？
真实数据是消费信贷申请主表；历史明细与证券账户字段未提供。仅交付可执行研究原型和这些字段的后续接入边界，不会以收入或贷款比率冒充证券指标。
