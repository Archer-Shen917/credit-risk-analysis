# 复现与问题登记

## 稳定的实验顺序

1. 校验输入SHA-256、ID唯一、TARGET合法；固定7:3分层划分。
2. 拟合区学习预处理、WOE、IV、相关性和VIF；调参区早停及网格比较。
3. 冻结主模型与特征取舍；仅拟合+调参复训；独立校准集拟合Platt映射。
4. 独立策略区确定三档边界及诊断分类阈值；测试集只评价，不回写参数。
5. 全局随机SHAP、六个按分数位置选择的案例、群体诊断、经济情景及PDF。

## 实际问题和处理

| 问题 | 处理 | 尚存限制 |

| 就业365243与零/负收入 | 显式缺失标记；安全比率，不删除客户 | 缺失业务原因仍未知 |

| 加权/SMOTE导致概率先验变动 | 在训练内处理，独立校准、检查Brier | 校准没有改善本次测试Brier |
| 少数类别造成不稳定审计比率 | XNA等小样本不当作比较参照 | 需要更大、有代表性的审核数据 |
| 券商指标与实际数据不匹配 | 用途、缺项和业务迁移条件显式登记 | 历史/证券指标未实测完成 |
| 格式检查器未安装 | 提供Black/isort/flake8/mypy/pylint配置及命令 | 本次不声称这些工具通过；须本地或CI复查 |

## 字段含义不能夸大

CREDIT_INCOME_RATIO是本笔贷款金额/记录收入，不是完整客户资产负债率。
ANNUITY_INCOME_RATIO未验证周期一致性，不叫“月供收入比”。
DEF_30/60_CNT_SOCIAL_CIRCLE是社交圈观测，不能改称本人历史逾期。
AMT_REQ_CREDIT_BUREAU_*是查询计数，不能替代所有历史申请。
缺少标签观察窗口、真实核销及回收，不能把TARGET当作已确认一年PD。

## 本地私有结果

逐客户预测仅写入outputs/private并被.gitignore排除。仓库只包含聚合统计和匿名案例，不含原始CSV或客户ID级评分表。正式对外使用前仍需检查原数据许可和授权范围。
